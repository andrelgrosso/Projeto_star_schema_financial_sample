# Projeto BI - Star Schema Financial Sample
Este repositório contém os arquivos do projeto de Business Intelligence focado na modelagem Star Schema utilizando a base de dados **Financial Sample**. O projeto faz parte de um curso de Power BI e inclui tanto os arquivos originais do curso quanto as versões modificadas conforme solicitado no desafio.

## 🎯 Objetivo do Projeto
Desenvolver um modelo de dados no formato **Star Schema** utilizando o Power BI, aplicando conceitos de:
- Modelagem dimensional
- Transformação de dados (ETL)
- Linguagem DAX (Data Analysis Expressions)
- Criação de medidas e colunas calculadas
- Visualização de dados
## 🛠️ Tecnologias Utilizadas
- **Microsoft Power BI** - Ferramenta de BI e visualização de dados
- **Excel** - Fonte de dados original
- **DAX** - Linguagem de fórmula para análise de dados
- **Star Schema** - Modelo de dados dimensional
## 📋 Requisitos
Para visualizar e editar os arquivos deste projeto, você precisará de:
- Microsoft Power BI Desktop (versão recente recomendada)
- Microsoft Excel (para visualizar a base de dados original)
- Microsoft Word ou leitor compatível (para os documentos .docx)
## 🚀 Como Usar
1. **Visualizar o projeto original:**
   - Abra o arquivo `Documentos_curso/star_schema_financial_sample.pbix` no Power BI Desktop
2. **Visualizar minha solução do desafio:**
   - Abra o arquivo `Meus_documentos/MeuProjeto_star_schema_financial_sample.pbix` no Power BI Desktop
3. **Consultar a documentação:**
   - Leia o arquivo `Meus_documentos/Modelagem e Transformação de dados com DAX com Power BI_meuprojeto.docx` para entender as decisões de modelagem
4. **Visualizar o esquema estrela:**
   - Abra a imagem `Meus_documentos/meu_esquema_estrela.png` para ver o diagrama do modelo dimensional
## 📊 Sobre a Base de Dados
A base **Financial Sample** contém dados financeiros de uma empresa multinacional, incluindo informações sobre:
- Vendas por país e segmento
- Lucros e receitas
- Produtos e categorias
- Períodos temporais
